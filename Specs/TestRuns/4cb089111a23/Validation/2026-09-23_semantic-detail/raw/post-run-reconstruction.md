# Post-run reconstruction of v4 and v5 frozen source copies

This note records a **post-run evidence repair**, not an input change before or during either native run. The v4 and v5 `candidate-inputs.json` manifests and `candidate-overlay.patch` files were retained unchanged. Their archived `inputs/` copies were absent or incomplete when curation was first attempted. V4 had 29 copied baseline files; those copies were not a qualified v4 snapshot. V5 had no `inputs/` directory. The first curator preflight stopped before writing repository output.

I reconstructed full 29-file v4 and v5 input trees under the permitted visualization directory from the v6 frozen `inputs/` tree. For each variant, 28 files are byte-identical to v6 according to all three original manifests. `VisualGallerySurfaces.cpp` was reconstructed by replacing only the semantic icon probe comment/tolerance/minimum block in v6 with the text recorded by the variant's retained `candidate-overlay.patch`. The v4 block uses the two-line small-outlined-glyph comment, tolerance 24, minimum 4; v5 adds the close-glyph tolerance comment, tolerance 64, minimum 4. Exact CRLF line endings in this block were selected by SHA-256 equality to the original frozen manifest, not by modifying its expected hash. V6 uses tolerance 64 and minimum 1 with a different explanatory comment.

The reconstructed v4 witness file hashes to `6dc482a337960adad927368c4588bbec97767f13358c6b8d0b4fe419fcf07d57`; v5 hashes to `307960ae85529d855518c4b127830f51a0a885a3bf3adf93dcf8c8d29560e832`. All 29 files in each reconstructed tree match their respective original `candidate-inputs.json` SHA-256 entries (29/29). The two trees are `semantic-detail-reconstructed-inputs/v4/inputs` and `semantic-detail-reconstructed-inputs/v5/inputs` relative to this note's directory. Copy them into each matching external evidence folder's `inputs/` directory, replacing v4's invalid baseline copies and creating v5's missing directory. Preserve the original manifests and patches exactly.

The rebuilt source copies establish byte equality with the manifests; they do not prove the copies themselves were present when v4/v5 ran. The original build receipts, logs, source snapshot IDs, candidate patches, failed galleries and disk-audit receipts remain the run provenance. V4/v5 must continue to be labeled failed gallery attempts, never final passes. The external curator should archive this note alongside the source and run receipts so the reconstruction timing remains visible.
