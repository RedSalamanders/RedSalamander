# Hosted modal focus-return diagnostic

The [private x64 diagnostic run](https://github.com/RedSalamanders/RedSalamander/actions/runs/42470431914) compared the canonical hosted boundary against a one-line private transformation on the same disposable runner. The canonical control closed a test-owned modal and viewer and did not return foreground to the owned neutral window; its child exit 11 is the expected retained control failure. With the tool-window style also cleared on that already-verified owned neutral window, three repetitions returned the exact foreground and focus. Input remained unchanged. The transformation changes no restoration guard or assertion.

The executed transformed initializer has the SHA-256 recorded in `results.json`; the product fix uses those exact initializer bytes. Evidence includes selected original stdout rows, byte offsets and complete member and artifact hashes. The complete artifact and job log are retained separately. This is a focused controlled diagnostic, not hosted Full, ARM64 runtime, or production qualification. Windows may select other windows for other reasons; the guard still refuses an unrelated foreground. Only the test-owned boundary's style was changed; the original foreground was restored under the existing guard.
