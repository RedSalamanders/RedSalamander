# Synthetic background-mode PerfJsonl sink control

This is a synthetic logger control, not a filesystem read or ViewerSpace scan. It calls `Debug::detail::WritePerfJsonl` directly using the same synthetic metric label `FileSystem.DirectoryOps.Enumerate`, a synthetic 1µs duration, and a 300-character detail. The label does not mean a directory was enumerated. There were 10,000 calls total, zero warm-up calls, and two clock reads per call. The sink-on cases emitted 6,000 JSONL rows; sink-off batches emitted none. Exact results and source are preserved as `results.json` and `source.txt`. The raw JSONL is split into three 2,000-row shards; concatenate `perf-raw-0001.jsonl`, `perf-raw-0002.jsonl`, and `perf-raw-0003.jsonl` for the original bytes. The manifest stores source hash/length/row count, byte offsets, line ranges, and each shard hash/length.

Each normal-priority case requested and completed 1,000 calls. Priority entry/restore counters and errors were zero. Each background-priority case also completed 1,000 calls: the single-thread batch had one priority entry, restore attempt and restoration; the eight-thread batch had eight of each. Both background batches had zero begin/restore failures and zero last Win32 error. The background-priority sink-on totals were 88.6683 ms (single-thread, 88.7170 ms wall) and 381.4338 ms (eight-thread sum, 85.0687 ms wall); per-call max was 1.1105 ms and 61.5700 ms, respectively. Sink-off background batches retained the requested priority transitions but had 19.7 µs total measured call time in each batch. Refer to `results.json` for every individual reported field and round.

Per root run context, the standalone source was compiled by pinned Visual Studio 18 MSVC with `/std:c++latest /EHsc /O2 /MD /W4`, with zero compiler warnings. The exact abfd build receipt payload is included. `binary-identities.txt` records the executable and Release `Common.dll` source paths, hashes and lengths; neither binary is copied. The receipt identifies the Release Common DLL dependency and is not a standalone microbenchmark qualification receipt.

These measurements isolate synthetic logger calls with background priority transitions. They do not establish real filesystem-operation observer cost, scan cost, or a product gain. Do not infer a full-scan cause or gain from this control.
