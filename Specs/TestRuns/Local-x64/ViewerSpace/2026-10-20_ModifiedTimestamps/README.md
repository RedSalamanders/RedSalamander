# Space Viewer modified timestamps - 2026-10-20

The provider already supplies LastWriteTime, but Space Viewer discarded it from retained file and directory records. The repair carries those ticks through summaries, nodes, resolved selection and cache serialization, then displays Modified in the inspector and tooltip using the shared file-list local-time formatter. Missing, invalid and synthetic Other dates show Unavailable. Only the root uses an optional worker-side metadata read; child timestamps use the existing listing. No selection/hover/paint metadata I/O was added.
