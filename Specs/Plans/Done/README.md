# Completed work

Completed plans record sequencing, rationale, and evidence. Add a bullet to this index in the change that
moves a plan to Done. Put the newest entry first, link the title to its file, and follow it with an em dash
and its outcome.

The dated records in this folder carry the earlier history. Each completed plan file is frozen after the
change that adds it and admits its exact path in `Test-RSProtectedDoneHistory`. See the
[plan lifecycle](../../README.md#plan-lifecycle).
