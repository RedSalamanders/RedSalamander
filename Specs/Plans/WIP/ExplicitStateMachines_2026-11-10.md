## 1. Problem statement and architectural decision

Across `RedSalamander`'s executables, shared `Common` library, 16 plugin DLLs, and PowerShell build/validation modules, **37 implicit state machines** currently encode mutually exclusive or ordered protocol phases across correlated `bool` flags, sentinel integers (`0`, `-1`, `UINT64_MAX`), overloaded `nullptr` / handle states, `thread_local` pointers, and uncoordinated file/directory states. Whenever $k$ flags encode $k + 1$ legal phases ($2^k \gg k + 1$), teardown, cancellation, timeout, focus-loss, or fallback paths easily omit one field update—producing **31 concrete, source-verified state-coherence defects (`RS-SM-01`..`RS-SM-31`)** cataloged in [Section 4](#4-verified-implicit-state-machine-defect-ledger).

### Core non-breaking decision (UX + DX + AX)

Keep **100% of public C++ and COM/POD plugin ABIs (`Common/PlugInterfaces/*`), `Specs/SettingsStore.schema.json`, Portable ZIP layouts, CLI switches, and CI workflow contracts unchanged**, and refactor **private implementation state** (`Impl`, `State`, anonymous-namespace controllers, and PowerShell module records) using four zero-overhead patterns:

1. **Pattern A — Flat `enum class Phase : uint8_t` + centralized `TransitionTo()`**: Used for service/daemon lifecycles, async readers/writers, directory cursors, and hot-path render/enumeration controllers. Switches omit `default:` so MSVC `/Wall` (`C4061`/`C4062`) rejects unhandled phases at compile time.
2. **Pattern B — Inline value-type `std::variant<std::monostate, ...>`**: Used inside private `State`/`Impl` structs for mutually exclusive UI modes, pointer gestures, inline confirmation banners, and modal capture sessions—zero heap allocation on steady-state paths and single-statement reset (`state.emplace<std::monostate>()`).
3. **Pattern C — RAII transition guards (`wil::scope_exit`), COM self-pins (`wil::com_ptr<Self>`), and persistent/heap-owned `OVERLAPPED` slots**: Prevents stack-use-after-return on cancelled/timed-out overlapped pipe I/O, prevents modal file-dialog re-entrancy UAFs, and ensures early-return error paths roll back optimistic status transitions.
4. **Pattern D — Discriminated PowerShell state records (`[pscustomobject]@{ Kind = '...' }`) + mutex-guarded staged `~<guid>`/`.tmp` atomic moves**: Eliminates cross-architecture `DxUi` clone races, multi-mutator promotion clobbers in `ValidationEvidence.psm1`, and unverified PR delegation in `ScopedTesting.psm1`.
